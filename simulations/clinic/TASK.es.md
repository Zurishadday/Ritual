# Tarea: solicitud de citas de un consultorio

Paquete: `web`. Se le da al constructor tal cual, sin nada más.

---

Necesito una página web para mi consultorio de fisioterapia, «Fisio Andares». Quiero:

- Una portada con una foto y una frase que diga qué hacemos.
- Los tres tratamientos que damos (rehabilitación de rodilla, dolor de espalda, masaje deportivo), cada uno con su foto, cuánto dura la sesión y el precio.
- Un formulario para pedir cita: nombre, teléfono, correo, el tratamiento, el día y la hora que prefieren (atendemos de lunes a viernes, de 9 a 18) y un comentario opcional. Que guarde las solicitudes en el servidor.
- Una página para mí, protegida con contraseña, donde vea las solicitudes, las más nuevas primero, y pueda marcar cada una como confirmada o cancelada.
- La dirección y un teléfono para llamar.
- Que se vea bien en el celular.

Sin frameworks: HTML, CSS y JavaScript, y un servidor pequeño en Node sin dependencias. Para las fotos usa imágenes de ejemplo. Déjalo listo para correr con `node servidor.mjs` y dime cómo lo pruebo.
